Network Security

ความปลอดภัยเครือข่าย - ปกป้องข้อมูลที่วิ่งไปมาระหว่างคอมพิวเตอร์
อธิบายง่ายๆ เหมือน รปภ. หมู่บ้าน

แฮกเกอร์นั่งอยู่ในร้านกาแฟ เปิดโน้ตบุ๊คดักจับข้อมูลผ่าน Wi-Fi สาธารณะ ลูกค้าที่กรอกเลขบัตรเครดิตซื้อของออนไลน์ ข้อมูลถูกดักอ่านทั้งหมด เพราะ Wi-Fi ไม่เข้ารหัส และเว็บไซต์ไม่ใช้ HTTPS นี่คือเหตุผลที่ Network Security สำคัญมาก

Network Architecture: Internet → Firewall → DMZ / IDS·IPS → Internal Network (with VPN & NAC)

OSI Model แบบเข้าใจง่าย

Open Systems Interconnection - 7 Layers
เปรียบเทียบ: ส่งจดหมายหาเพื่อน
7. Application = เขียนจดหมาย (เนื้อหาที่คุณต้องการส่ง)
6. Presentation = ใส่ซอง เข้ารหัสถ้าเป็นความลับ (แปลงรูปแบบข้อมูล)
5. Session = ไปที่ไปรษณีย์ เปิดบริการส่ง (เปิด/ปิดการเชื่อมต่อ)
4. Transport = เลือกส่ง EMS รับประกัน (TCP) หรือไปรษณีย์ธรรมดา (UDP)
3. Network = เขียนที่อยู่ผู้รับ (IP Address, Routing)
2. Data Link = บุรุษไปรษณีย์ส่งถึงบ้าน (MAC Address, Switch)
1. Physical = ถนนที่รถไปรษณีย์วิ่ง (สายเคเบิล, Wi-Fi, สัญญาณไฟฟ้า)

จำง่ายๆ: ชั้นบนสุด = ใกล้คน (Application) ชั้นล่างสุด = ใกล้สาย (Physical)

TCP/IP Basics

Transmission Control Protocol / Internet Protocol
TCP vs UDP:
- TCP = ส่งพัสดุ EMS มีเลข Tracking ผู้รับต้องเซ็นรับ ถ้าหายส่งใหม่ (เชื่อถือได้ แต่ช้ากว่า)
- UDP = โยนจดหมายใส่ตู้ไปรษณีย์ ไม่รู้ถึงหรือเปล่า (เร็ว แต่ไม่รับประกัน เช่น Video Call, Gaming)
  • TCP - Connection-oriented, 3-way handshake (SYN, SYN-ACK, ACK), ใช้กับ HTTP, Email, FTP
  • UDP - Connectionless, ไม่มีการตรวจสอบ ใช้กับ DNS, VoIP, Streaming
  • IP Address - "ที่อยู่" ของอุปกรณ์ในเครือข่าย (IPv4: 192.168.1.1 / IPv6: ยาวกว่า)
  • Port - "เลขห้อง" ของบริการ เช่น Port 80 = HTTP, 443 = HTTPS, 22 = SSH

Firewall

กำแพงไฟ - ด่านตรวจเครือข่าย
เปรียบเทียบ: รปภ. หน้าประตูหมู่บ้าน
มีรายชื่อว่าใครเข้าได้ ใครห้ามเข้า (Allow/Deny List)
ตรวจทุกคนที่จะเข้า-ออก ถ้าไม่อยู่ในรายชื่ออนุญาต ไม่ให้ผ่าน
  • Packet Filtering - ตรวจแค่ "ซองจดหมาย" (IP, Port) ไม่เปิดอ่านเนื้อหา - เร็วแต่ไม่ละเอียด
  • Stateful Inspection - จำ "บทสนทนา" ได้ ตรวจว่า Packet นี้เป็นส่วนหนึ่งของ Connection ที่อนุญาตหรือไม่
  • Next-Gen Firewall (NGFW) - ตรวจถึงระดับ Application ดูว่าเป็น Facebook, YouTube หรือ Malware
  • WAF (Web Application Firewall) - เฉพาะทางสำหรับเว็บ กัน SQL Injection, XSS

IDS vs IPS

Intrusion Detection System vs Intrusion Prevention System
เปรียบเทียบ:
- IDS = กล้องวงจรปิด - เห็นขโมย แจ้งเตือน แต่จับเองไม่ได้ (Passive, detect only)
- IPS = รปภ. ติดอาวุธ - เห็นขโมยก็จับเลย บล็อค Traffic ทันที (Active, block + alert)
  • Signature-based - จับจากลายเซ็นที่รู้จัก เหมือนภาพคนร้ายที่ติดบอร์ด (รู้จัก = จับได้ ไม่รู้จัก = รอด)
  • Anomaly-based - จับจากพฤติกรรมผิดปกติ เช่น Login 100 ครั้งใน 1 นาที (จับ Zero-day ได้ แต่อาจ False Positive)
  • Heuristic-based - ใช้กฎ + AI วิเคราะห์รูปแบบ

VPN (Virtual Private Network)

อุโมงค์ลับเข้ารหัส
เปรียบเทียบ: ปกติคุณขับรถบนถนนสาธารณะ ทุกคนเห็นรถคุณ (Internet ปกติ)
VPN คือสร้างอุโมงค์ลับให้รถคุณวิ่ง ข้างนอกมองไม่เห็นว่าใครอยู่ข้างใน ไปไหน ขนอะไร (เข้ารหัส Traffic ทั้งหมด)
  • Site-to-Site VPN - เชื่อมสำนักงาน 2 แห่ง เหมือนสร้างอุโมงค์ระหว่าง 2 อาคาร
  • Remote Access VPN - พนักงาน WFH เชื่อมเข้าออฟฟิศจากที่บ้าน
  • IPsec - โปรโตคอลเข้ารหัสที่ Layer 3 (Network Layer)
  • TLS/SSL VPN - ทำงานผ่าน Browser ไม่ต้องลง Software พิเศษ

DMZ, NAC, VLAN

เครื่องมือแบ่งส่วนเครือข่าย
เปรียบเทียบ: โรงพยาบาล
- DMZ = ล็อบบี้ต้อนรับ คนนอกเข้าได้ แต่เข้าห้องผ่าตัดไม่ได้ (เขตกันชนระหว่าง Internet กับ Internal Network)
- VLAN = แยกตึกผู้ป่วย ตึกแพทย์ ตึกธุรการ ไม่ให้ปะปนกัน (แบ่ง Network เสมือน)
- NAC = เช็คว่าเครื่องที่จะเชื่อมต่อ Healthy ไหม มี Antivirus, Update หรือยัง ถ้าไม่ผ่าน ไม่ให้เข้า
  • DMZ (Demilitarized Zone) - วาง Public-facing Server (Web, Email) ไว้ตรงนี้ ถ้าถูกเจาะ ยังไม่ถึง Internal
  • VLAN (Virtual LAN) - แบ่ง Network ด้วย Switch โดยไม่ต้องแยกสายจริง ลด Broadcast Storm
  • NAC (Network Access Control) - ตรวจสุขภาพอุปกรณ์ก่อนอนุญาตเข้าเครือข่าย

Wireless Security

ความปลอดภัย Wi-Fi
วิวัฒนาการ Wi-Fi Security:
WEP (อย่าใช้!) = ล็อคบ้านด้วยกุญแจพลาสติก หักง่ายมาก
WPA2 (ดี) = ล็อคบ้านด้วยกุญแจเหล็ก + Deadbolt
WPA3 (ดีที่สุด) = ล็อคบ้านด้วยกุญแจ Digital + สแกนนิ้ว
  • WPA2-Enterprise - ใช้ RADIUS Server ยืนยันตัวตน เหมาะกับองค์กร
  • WPA2-Personal - ใช้ Pre-Shared Key (PSK) = รหัสผ่าน Wi-Fi ที่บ้าน
  • WPA3-SAE - ป้องกัน Dictionary Attack แม้รหัสผ่านง่ายก็เจาะยากขึ้น

Zero Trust

"ไม่ไว้ใจใครเลย" ต้องพิสูจน์ตัวทุกครั้ง
เปรียบเทียบ: แบบเก่า = คนในบ้านไว้ใจหมด (Trust but Verify)
Zero Trust = แม้คนในบ้านก็ต้องสแกนบัตรทุกครั้งที่เปิดประตู "Never Trust, Always Verify"
  • ไม่ว่าจะอยู่ใน Network ภายในหรือภายนอก ต้องพิสูจน์ตัวตนเสมอ
  • ใช้ Micro-segmentation แบ่งเครือข่ายเป็นส่วนเล็กๆ
  • Least Privilege Access ทุกจุด
  • ตรวจสอบ + Log ทุก Request แบบ Real-time

Common Network Attacks

การโจมตีเครือข่ายที่พบบ่อย
  • Man-in-the-Middle (MITM) - แฮกเกอร์แอบนั่งกลาง ดักฟังข้อมูลระหว่างคุณกับเซิร์ฟเวอร์ เหมือนมีคนแอบเปิดอ่านจดหมายก่อนส่งต่อ ป้องกัน: ใช้ HTTPS, VPN
  • DoS / DDoS - ส่ง Traffic ท่วมจนระบบล่ม เหมือนจ้างคน 1 ล้านคนโทรเข้า Call Center พร้อมกัน ป้องกัน: DDoS Mitigation, CDN, Rate Limiting
  • ARP Spoofing - หลอกว่า "ฉันคือ Gateway" เพื่อดักจับ Traffic ใน LAN ป้องกัน: Dynamic ARP Inspection, Static ARP
  • DNS Poisoning - เปลี่ยนชี้ทาง DNS ให้คุณไปเว็บปลอม ป้องกัน: DNSSEC
  • Rogue AP - ตั้ง Wi-Fi ปลอมล่อเหยื่อ ป้องกัน: Wireless IDS, NAC
